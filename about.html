About the project

Formatting question papers should be straightforward.

Question Paper Maker turns structured text into a clean, multi-page A4 document without requiring an account, subscription or server upload.

Open the maker View source on GitHub
Focused

It formats questions you provide. It does not generate or alter academic content.

Private

Your paper stays in the browser. Drafts are stored only in local browser storage.

Open

The tool is free to use, open source and designed for static hosting.

What it provides

A live multi-page A4 preview, configurable examination headers, section and marks formatting, optional student fields, local draft saving, editable DOCX export and print-ready PDF output.

PDF is intended for exact final output. DOCX is provided when the paper must remain editable in Microsoft Word or compatible software.
